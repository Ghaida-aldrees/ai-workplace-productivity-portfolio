## Key Learnings

Through this portfolio, I learned that effective AI use depends on clear prompts, structured workflows, verification, and human judgment.

AI can help organize information, improve communication, and support planning, but outputs should be reviewed before being used in a professional environment.

## Responsible Use Statement

AI should be used responsibly and with appropriate human oversight.

Workplace information should be handled according to applicable organizational requirements. Confidential, personal, or sensitive information should not be entered into AI tools unless the use is explicitly authorized and appropriate safeguards are in place.

AI-generated content should be reviewed for accuracy, unsupported assumptions, bias, privacy, and confidentiality before use.
