# Verification Checklist

## Purpose

This checklist is used to verify AI-generated workplace outputs before they are used or shared.

## Verification Checklist

| Check | Question |
|---|---|
| Accuracy | Are the statements supported by the provided information? |
| Completeness | Are the important points included? |
| No Fabrication | Did AI add any information that was not provided? |
| Dates & Numbers | Are dates, numbers, and figures accurate? |
| Missing Information | Is unavailable information clearly marked as `[Not Specified]`? |
| Relevance | Is the output focused on the actual workplace task? |
| Tone & Format | Is the output appropriate for the intended audience and purpose? |
| Human Review | Has a human reviewed the final output before use? |

## Applied to a Portfolio Output

### Output Reviewed

The verification checklist was applied to the **Information Processing Workflow**.

### Findings

| Verification Area | Finding |
|---|---|
| Accuracy | Information should be checked against the original project input. |
| Completeness | The final structure includes the main project information categories. |
| No Fabrication | The workflow explicitly instructs AI not to invent information. |
| Dates & Numbers | Dates and numbers should be verified against the source before use. |
| Missing Information | Missing information is marked as `[Not Specified]`. |
| Relevance | The output is focused on organizing project information into a structured update. |
| Tone & Format | The output uses concise, professional language and a structured table. |
| Human Review | A Project Coordinator reviews the output before it is used. |

## Key Learning

AI output should not be accepted automatically. A verification checklist helps identify unsupported information, missing details, incorrect dates or numbers, and other issues before the output is used in a workplace context.

**Human review remains necessary before sharing or relying on AI-generated information.**
