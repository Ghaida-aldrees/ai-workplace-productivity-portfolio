# Verification Checklist

## Purpose

This checklist is used to review AI-generated workplace outputs before they are used or shared.

## Verification Checklist

| # | Verification Check                                                | Result          |
| - | ----------------------------------------------------------------- | --------------- |
| 1 | Are the facts supported by the provided information?              | Pass            |
| 2 | Has the AI avoided inventing information?                         | Pass            |
| 3 | Are dates, statuses, and other details accurate?                  | Pass            |
| 4 | Is missing information clearly identified as `[Not Specified]`?   | Pass            |
| 5 | Is the output clear and logically structured?                     | Pass            |
| 6 | Is the language appropriate for a professional workplace context? | Pass            |
| 7 | Does the final output require any human correction before use?    | Review Required |

## Applied Verification

### Output Reviewed

The **Improved Project Status Prompt** from the Before & After example was reviewed using the checklist above.

### Findings

| Check                   | Finding                                                                                                                       |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Facts supported         | The prompt explicitly requires the AI to use only the provided project information.                                           |
| No invented information | The prompt states: "Do not invent information that is not provided."                                                          |
| Dates and status        | The prompt requires project information to be reviewed, but actual dates and status must still be checked against the source. |
| Missing information     | `[Not Specified]` is used when information is unavailable.                                                                    |
| Structure               | The output is organized into Overall Status, Key Progress, Risks/Issues, and Next Steps.                                      |
| Professional language   | The prompt requests concise and professional business language.                                                               |
| Human review            | Human review remains necessary before the output is shared or used.                                                           |

## Verification Outcome

The output passed the main verification checks.

However, **human review is still required** to confirm that project-specific facts, dates, status, risks, and next steps accurately reflect the original source information.

## Key Principle

AI-generated content should be verified before use. A structured output can improve clarity, but it does not replace human review and accountability.
