# Responsible AI Use Checklist

## Purpose

This checklist defines how AI should be used responsibly when supporting workplace project coordination tasks.

## Responsible AI Principles

| Principle       | How It Applies to Project Coordination                                                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accuracy        | AI-generated information should be checked against the original source before use.                                                                       |
| Accountability  | The Project Coordinator remains responsible for reviewing and approving the final output.                                                                |
| Confidentiality | Confidential company, project, customer, or employee information should not be entered into AI tools unless the organization has explicitly approved it. |
| Privacy         | Personal or identifying information should be protected and should not be shared unnecessarily.                                                          |
| Bias            | AI outputs should be reviewed for unfair assumptions, misleading wording, or biased conclusions.                                                         |
| Human Oversight | A human should review important AI-generated outputs before they are shared or used for decisions.                                                       |

## Information Classification

| Information Type                     | Classification | Example                                                                                         | Responsible Use                                                                                            |
| ------------------------------------ | -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| General project-management templates | Green          | Generic project status template                                                                 | Can be used with AI when no confidential information is included.                                          |
| Internal project information         | Amber          | Internal project status or non-public project details                                           | Use only when organizational policy allows it and avoid unnecessary sensitive details.                     |
| Confidential or personal information | Red            | Customer data, employee personal information, credentials, or confidential business information | Do not enter into AI tools unless explicitly authorized and protected by approved organizational controls. |

## Responsible AI Checklist

Before using an AI-generated output, check:

* [ ] Is the information accurate and supported by the source?
* [ ] Have confidential or sensitive details been protected?
* [ ] Has unnecessary personal information been removed?
* [ ] Could the output contain bias or unsupported assumptions?
* [ ] Has a human reviewed the output?
* [ ] Is the use of AI appropriate for the task and workplace context?
* [ ] Does the final output comply with applicable organizational requirements?

## Human Responsibility

AI can support project coordination activities such as organizing information, drafting updates, and structuring plans. However, the Project Coordinator remains responsible for reviewing the output and deciding whether it is appropriate to use.

AI should support human work, not replace human judgment or accountability.
