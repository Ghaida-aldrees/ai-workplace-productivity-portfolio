# Planning Workflow

## Goal

Create a clear and structured plan for coordinating a project and tracking its progress.

## Mechanisms

The plan uses AI to support:

* Breaking the goal into manageable activities.
* Organizing activities into logical phases.
* Creating clear and actionable tasks.
* Identifying information that still needs to be confirmed.

AI-generated planning content is reviewed by the Project Coordinator before use.

## Phases

### Phase 1: Define the Work

Identify the project objective, expected outcome, scope, and key information needed to begin the work.

### Phase 2: Organize Activities

Group the required activities into logical phases and identify the main tasks within each phase.

### Phase 3: Track Progress

Monitor task status, identify delays or issues, and follow up on outstanding activities.

### Phase 4: Review and Close

Review completed activities, confirm outstanding items, and document the final status.

## Tasks

| Phase               | Task                                              | Expected Output                   |
| ------------------- | ------------------------------------------------- | --------------------------------- |
| Define the Work     | Clarify the project goal and required information | Clear project objective           |
| Define the Work     | Identify key activities                           | Initial activity list             |
| Organize Activities | Group activities into phases                      | Structured project plan           |
| Organize Activities | Break phases into tasks                           | Actionable task list              |
| Track Progress      | Review task status                                | Updated progress view             |
| Track Progress      | Identify delays or issues                         | List of items requiring follow-up |
| Review and Close    | Confirm completed activities                      | Completion status                 |
| Review and Close    | Document outstanding items                        | Final follow-up list              |

## Human Review

The Project Coordinator reviews the plan to confirm that the tasks are relevant, realistic, and based on available information. AI should not be used to make unsupported assumptions about deadlines, responsibilities, or project requirements.

## Key Principle

AI can help structure and organize a project plan, while the Project Coordinator remains responsible for reviewing the plan and confirming that it reflects the actual project needs.
