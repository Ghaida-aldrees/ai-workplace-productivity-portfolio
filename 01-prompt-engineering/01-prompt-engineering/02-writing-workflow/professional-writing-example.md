# Professional Writing Workflow

## Workplace Task

Preparing a professional project status update for management.

## 1. Draft

The first draft is created using the available project information.

The draft focuses on:

* Current project status
* Key progress
* Risks or issues
* Next steps

The information is kept factual and based only on the available project data.

---

## 2. Verify

Before refining the draft, the information is reviewed to check:

| Verification Area   | Check                                                       |
| ------------------- | ----------------------------------------------------------- |
| Facts               | Are the statements supported by the provided information?   |
| Status              | Is the project status accurate?                             |
| Dates               | Are dates and deadlines correct?                            |
| Risks/Issues        | Are identified risks actually supported by the information? |
| Missing Information | Is any missing information clearly identified?              |
| Clarity             | Is the message easy to understand?                          |

---

## 3. Refine

After verification, the draft is improved by:

* Removing unnecessary wording.
* Organizing information into clear sections.
* Using concise and professional language.
* Highlighting important risks or issues.
* Making next steps easy to identify.
* Replacing unsupported assumptions with `[Not Specified]`.

### Refined Structure

| Section        | Content                              |
| -------------- | ------------------------------------ |
| Overall Status | Current project status               |
| Key Progress   | Main completed or ongoing activities |
| Risks/Issues   | Confirmed risks or issues            |
| Next Steps     | Required upcoming actions            |

---

## 4. Human Sign-off

The final output is reviewed by the responsible person before it is shared with management.

The human reviewer confirms that:

* The information is accurate.
* No unsupported information has been added.
* The wording reflects the actual project situation.
* Important information has not been omitted.
* The final message is appropriate for the intended audience.

## Final Workflow

**Draft → Verify → Refine → Human Sign-off**

AI can support the drafting and refinement stages, but the final output should be reviewed and approved by a human before use.
